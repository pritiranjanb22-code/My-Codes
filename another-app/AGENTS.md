# another-app - Project Agents

## Overview
Minimal Node.js starter project. Uses global ECC agents for all tasks.

## Agent Usage
- **planner**: New features, refactoring
- **tdd-guide**: Test-driven development for new functions
- **code-reviewer**: After writing code
- **security-reviewer**: Before commits
- **build-error-resolver**: When build fails

## Project Context
- Stack: Node.js (CommonJS)
- Entry: `src/index.js`
- Commands: `npm test`, `npm run build`

## ECC Compliance
- Follows global `~/.config/opencode/` agents, commands, skills
- No project-specific overrides needed
