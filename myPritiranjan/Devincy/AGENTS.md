# Devincy - Project Agents

## Overview
Android/Kotlin app with Jetpack Compose, Hilt, Room, Clean Architecture.

## Agent Usage
- **planner**: New features, Clean Architecture layers
- **tdd-guide**: JUnit/MockK unit tests, Compose/Espresso instrumented tests
- **code-reviewer**: Kotlin/Compose/Hilt patterns
- **security-reviewer**: Network security config, DataStore encryption
- **build-error-resolver**: Gradle/Kotlin build failures
- **go-build-resolver**: Not applicable

## Project Context
- Min SDK 24, Target SDK 34
- Packages: `data/`, `domain/`, `presentation/`, `di/`
- Build: `./gradlew build`, `./gradlew test`, `./gradlew connectedAndroidTest`
